## Akri HTTP POST Connector Services

This directory is the parent for the independent Rust service crate that implements the Akri HTTP
POST Connector runtime, including its `Cargo.toml`, committed `Cargo.lock`, `src/` tree, and
`Dockerfile`.

The service crate is added in a later implementation phase and is registered independently in the
repository's Rust CI coverage matrix, vulnerability scan matrix, and Codecov Rust paths, per
[.github/instructions/rust-crate-registration.instructions.md](../../../../.github/instructions/rust-crate-registration.instructions.md).
